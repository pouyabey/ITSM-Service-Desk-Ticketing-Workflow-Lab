# ITSM Service Desk Ticketing Workflow Lab

## Project Overview

This project documents a practical ITSM service desk workflow based on common support tickets in a field operations, agriculture, warehouse, or production environment.

The lab demonstrates how support tickets are received, categorized, prioritized, investigated, documented, escalated when needed, and resolved using a structured help desk process.

The scenarios include Wi-Fi connectivity, mobile application login issues, printer troubleshooting, access point connectivity, workstation setup, production application access, and high-volume ticket triage during peak season.

## Lab Objectives

- Create and manage realistic IT support tickets
- Document troubleshooting steps clearly
- Capture technical evidence through screenshots
- Practice ticket prioritization and escalation decisions
- Demonstrate customer service and operational support skills
- Simulate support for field operations, ranch locations, and packing environments
- Build a GitHub portfolio project for IT Help Desk, IT Support Technician, and Systems Support roles

## Tools Used

## Example Workflow

1. User reports an issue through the service desk.
2. Ticket is created and assigned a category, priority, and status.
3. Initial troubleshooting steps are documented.
4. Evidence is captured through screenshots.
5. Root cause is identified where possible.
6. Resolution or escalation steps are completed.
7. Ticket is updated and closed with final notes.

## Peak Season Support Simulation

This lab includes a high-volume ticket triage scenario that simulates normal daily ticket volume and peak-season ticket volume.

| Support Period | Ticket Volume |
|---|---|
| Normal Daily Volume | 3-5 tickets |
| Peak Season Volume | 15-30 tickets |

The triage workflow demonstrates how tickets can be reviewed, sorted by business impact, assigned priority, updated by status, monitored for SLA risk, and escalated when needed.
